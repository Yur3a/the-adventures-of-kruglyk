# Пригоди Круглика

Навчальна 2D-гра українською мовою: допоможи синьому Круглику розв’язати приклади на додавання та перемогти Лихих. Phaser 3, TypeScript і Vite, без UI-фреймворків, сервера або зовнішніх ігрових ресурсів.

## Запуск

Потрібен Node.js 22.13+.

```bash
npm install
npm run dev
```

Відкрий адресу, яку надрукує Vite (зазвичай http://127.0.0.1:5173).

```bash
npm run build       # перевірка TypeScript і production-збірка у dist/
npm run preview     # локальний перегляд production-збірки
npm run typecheck   # лише перевірка типів
npm test            # перевірка прикладів, циклу чисел і черги восьми Лихих
```

Для браузерних перевірок:

```bash
npx playwright install chromium
npm run test:e2e
```

Playwright сам запускає dev-сервер, якщо він ще не працює. Тести перевіряють клавіатуру, утримання клавіш, перехід 20 → 0, неправильну і правильну відповіді, фіксацію числа під час пострілу, захист від подвійних атак, перезапуск і керування дотиком. Знімки екрана зберігаються в `test-results/`.

## Як грати

- **Space** — збільшити число Круглика на один: 0 → 1 → … → 20 → 0. Утримання клавіші не повторює дію.
- **Enter** — випустити енергетичну кулю. Відповідь фіксується в момент пострілу.
- Правильна відповідь дає **1 очко**, після короткої анімації з’являється новий Лихий.
- Неправильна відповідь викликає червону реакцію; приклад і рахунок залишаються. Правильна відповідь не розкривається.
- Кнопки на ігровому полі працюють мишею та дотиком; на вузьких екранах є додаткові великі кнопки.
- **Спочатку** — почати нову гру з нуля.
- **На весь екран** — розгорнути гру; **Esc** або **Згорнути** — повернутися. Число, приклад і рахунок зберігаються. Якщо браузер не підтримує справжній повноекранний режим, гра займає всю доступну область вкладки.

Немає таймера, штрафів чи кінцевого рівня. Число після перемоги зберігається, рахунок діє до перезапуску/оновлення сторінки. Обидва доданки завжди додатні, тому суми лежать у межах **2–20** (підмножина дозволеного діапазону 1–20).

У грі вісім Лихих: рогатий **Буркотун**, вогняний **Жарик**, слизень **Капосник**, пухнаста **Колючка**, хмаринка **Хмарник**, кристал **Кристалик**, гриб **Грибун** та одноокий **Зубчик**. У кожного власні форма, палітра, обличчя й idle-анімація. Вони з’являються у випадковій черзі: усі вісім до повторення, без однакових персонажів поспіль на межі черг. Неправильна відповідь не змінює поточного Лихого. Складність прикладів однакова для всіх.

Графіка адаптується до розміру ігрового поля та щільності пікселів екрана: внутрішнє полотно збільшується від 960 × 540 до 3840 × 2160. Текст малюється з чотирикратною роздільною здатністю. Камера зберігає логічні координати 960 × 540, тому розміри персонажів і натискання кнопок узгоджені при зміні масштабу та повноекранного режиму.

## Структура

```text
src/
  main.ts                       # конфігурація Phaser, Canvas і масштабування
  style.css                     # контейнер і мінімальний інтерфейс сторінки
  scenes/
    BootScene.ts                # запуск основної сцени без завантаження assets
    GameScene.ts                # цикл гри, атаки, перевірка відповіді та рахунок
  entities/
    Kruglyk.ts                  # синій герой, число, обличчя й анімації
    Enemy.ts                    # Лихий, картка прикладу, реакції та зникнення
    enemyVariants.ts            # вісім персонажів, імена, палітри та рух
    drawEnemy.ts                # окремий малюнок кожного Лихого
    Projectile.ts               # постріл із зафіксованою відповіддю
  systems/
    HighDpiRenderer.ts          # адаптивна роздільна здатність до 4K і камера
    EnemyRoster.ts              # випадкова черга без пропусків і повторів поспіль
    InputController.ts          # одиночні натискання і очищення слухачів
    MathProblemGenerator.ts     # випадкові додавання до 20
  ui/
    GameHud.ts                  # рахунок, підказки та кнопки всередині Canvas
    fullscreen.ts               # повноекранний режим і синхронізація розмірів
  utils/
    constants.ts                # розміри 960 × 540, координати, цикл 0–20
    drawLandscape.ts            # процедурна галявина з Phaser Graphics
tests/
  math.test.mjs                 # математичні інваріанти
  enemies.test.mjs              # повнота та неповторюваність черги Лихих
  browser/game.spec.ts          # перевірки гри у справжньому браузері
```

Основна логіка — у `GameScene.ts`. Стани `ready`, `shooting`, `celebrating` обмежують атаки до одного пострілу одночасно. `Projectile` зберігає відповідь незалежно від подальших натискань Space. Генератор не повторює попередній приклад. При перезапуску сцена прибирає слухачі клавіатури й дотику; Phaser очищає її об’єкти, анімації та таймери.

Уся ігрова графіка створюється локально за допомогою Phaser Graphics, тексту та геометричних фігур. Шрифти системні; мережеве завантаження зображень, звуків чи шрифтів під час гри не потрібне. `public/favicon.svg` — локальна іконка вкладки.

Довідка: [Phaser Scale Manager](https://docs.phaser.io/phaser/concepts/scale-manager), [Vite](https://vite.dev/guide/).
